# AI Personal Fashion Stylist 👗

## Project Overview
This is a Computer Vision and Generative AI project built as part of my MCA portfolio. The goal is to create a system that:
1. Identifies clothing items from user-uploaded images.
2. Extracts dominant colors and suggests matching palettes using Color Theory.
3. Recommends trending styles (e.g., Japanese trousers, Minimalist aesthetics).
4. Generates a visual preview of the recommended outfit.

## Tech Stack (Planned)
- **Language:** Python
- **AI/ML:** OpenCV, Scikit-learn, TensorFlow/PyTorch
- **Generation:** Stable Diffusion (via Hugging Face)
- **Deployment:** Streamlit / GitHub Pages# Personal-AI-Stylist
